Entry for the make.fun **Unsent: The Micro-Confession Sprint** — a two-part micro-confession: a "To:" line addressed to the sender's younger sister, followed by a single unsent sentence about the last voice note she ever sent. The program prints exactly those two lines and nothing else.

## Run

```sh
node main.ts
```
